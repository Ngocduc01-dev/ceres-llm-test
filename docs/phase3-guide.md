# Phase 3 – Gom context cho từng unit

- **Chạy:** `bash scripts/phase3.sh`
- **Đầu ra:** `data/context/<id>.txt` (1,540 file, trần <= 7,500 tokens) và `reports/context/summary.txt`.
- **Cấu trúc mỗi file `<id>.txt`:** `[1. TARGET]`, `[2. INCLUDES]`, `[3. CALL RULES]`, `[4. CLASS]`, `[5. TYPES]`, `[6A/6B. CALLEES]`, `[7. HELPERS]`, `[8. SAMPLE TESTS]`.
